# KADOS service

This service targets the DAISY Online Delivery
Protocol (DODP). Both protocol versions shipped by
Kolibre-KADOS are supported through the
OpenAPIAdapter:

- DODP v1 (all required operations)
- DODP v2.0.2 (all required and some optional
  operations)

Specifications:

- DODP v1:
  http://www.daisy.org/projects/daisy-online-delivery/drafts/20100402/do-spec-20100402.html
- DODP v2.0.2:
  http://www.daisy.org/projects/daisy-online-delivery/2-0/DODP2-0-2.html
